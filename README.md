## English

Most music apps want you to stream, subscribe, or sign up. LogaRhythm doesn't. It just plays the files you already have.

No cloud, no account, no ads. Your library stays on your device — organized, searchable, and yours.

---

Built with Kotlin and Jetpack Compose for Android 8.0+. Apache 2.0.

## فارسی

اکثر اپ‌های موسیقی می‌خواهند استریم کنید، اشتراک بخرید یا ثبت‌نام کنید. LogaRhythm هیچ‌کدام از اینها را نمی‌خواهد. فقط فایل‌هایی که دارید را پخش می‌کند.

بدون ابر، بدون حساب کاربری، بدون تبلیغات. کتابخانه‌تان روی گوشی خودتان می‌ماند — مرتب، قابل‌جستجو، و مال خودتان.

---

### امکانات

پخش محلی با صف قابل‌جابه‌جایی، متن همگام از فایل یا اینترنت، ویرایشگر تگ با بازگردانی خودکار، ReplayGain و اکولایزر، میکس‌های روزانه، آمار گوش‌دادن، ویجت صفحهٔ اصلی و پشتیبان‌گیری کامل.

رابط فارسی و انگلیسی. تم رنگی از کاور آلبوم یا والپیپر.

---

### ساخت

```bash
git clone https://github.com/Yasinjahantigh/LogaRhythm-Android.git
cd LogaRhythm-Android
./gradlew :app:assembleDebug
```

نیاز به JDK 21 و Android SDK 36. در ویندوز از `gradlew.bat` استفاده کنید.
